##### 跨时钟域同步 (CDC)：

- full 信号是由写指针与同步后的读指针比较产生的，必须在 wr_clk 下采样。

- empty 信号是由读指针与同步后的写指针比较产生的，必须在 rd_clk 下采样。

##### 指针编码（格雷码）：

为了防止多位数据同步时产生的亚稳态问题，读写指针在跨时钟域传输前，通常会先转换为格雷码（Gray Code）。因为格雷码相邻数据只有一位变化，可以有效降低同步器采样的风险。


#### 满/空判断逻辑：

- 空状态： 当读指针与同步后的写指针完全相等时，empty 拉高。

- 满状态： 当写指针与同步后的读指针在最高位不同、其余位完全相同时（对于双深度的幂次方FIFO），full 拉高。
